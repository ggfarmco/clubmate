# UI bug classes fixed in Clubmate

| Symptom | Root cause | Fix | Commit |
|---|---|---|---|
| `/` command popup covers the window and slides under the title bar | ~80 rows in a plain `VStack`, no height cap | Capped `ScrollView` + `LazyVStack`, `scrollTo` on highlight | composer popup fix |
| Transcript draws under the session header | Scroll content bleeds outside its frame | `.clipped()` on the scroll container | c674d67 |
| Composer controls widen the window, rail disappears after restart | Rigid `HStack` of pickers with a large ideal width | `ViewThatFits` → `FlowLayout`, `minWidth: 0`; later options behind one menu | 5a1f5c3, 7a5cb01 |
| Attachment labels ignore the font size setting | `Equatable` parent compares only `node`, never re-renders on theme change | Themed part in a child view with its own `@Environment(\.theme)` | 4f8d4d4 |
| Composer draft lost on section switch | `@State` model dies with the view | `ComposerDrafts` store keyed by node id | 4cdef7b |
| Text typed during a send is wiped | Draft cleared without checking what was sent | Clear only if text still equals the sent text | 2596ff1 |
| Tool card collapses while streaming | Expansion keyed by a group id that changes | Key by stable card ids, prune on transcript change | 33b88bf |
| Expanded last item stays off-screen | No scroll after expanding | `scrollTo(edge: .bottom)` when the last item opens | b8865b0 |
| Fuzzy picker list jumps, wrong row scrolled | `ForEach`/`scrollTo` keyed by index | Stable `id`, `scrollTo(item.id)` with bounds check | e0dc3f9 |
| Tree cursor hides rows under sticky headers | `scrollTo(id)` ignores pinned headers | `TreeCursor.scrollTarget(..., limit:)` | 237cff4 |
| Trigger flow's first port dot and focus ring touch the sidebar divider | Every leaf renderer padded itself by the gutter and `FlowNodeView` forgot | The gutter moved into `SDUINodeView` (`SDUIGutter.pads`), renderers no longer pad themselves | c34c1cbf, refactor(sdui) pane gutter |
| Overlay shortcut closes the overlay instead of focusing it | Toggle ignores focus | Focus the field if the overlay is open | e0dc3f9 |
| Rail not reachable by keyboard | `onTapGesture` | Real `Button` with `.buttonStyle(.plain)` | 857a76c |
| Key monitor eats terminal keys or leaks | No first-responder check, no teardown | Shared `.keyMonitor(active:handle:)` | 1627793, 48176d7 |
| Leader key stays armed after blur | Focus loss not handled | Reset on `onChange(of: focused)` | 6601c9d |
| Enter approves a permission prompt | "Allow" is the default first responder | `refusesFirstResponder`, `initialFirstResponder = dismiss` | 77ddf8b |
| Placeholder overlaps typed text in a popover | NSTextField placeholder | Nil placeholder while text is non-empty | 4723261 |
| Selected palette row unreadable | `theme.selection` background | fg 0.06 background + 2pt accent bar | b6a2cf8 |
| Settings window wrong size | `.fixedSize` per tab | Fixed frame | 857a76c |
| Light/dark switch needs a relaunch | Appearance read once at init | Observe `effectiveAppearance` | 54d4840 |
| Sparkline fixed size | `.frame(width: 60, height: 16)` | Height from server, `maxWidth: .infinity` | 715a3e5 |
| Alert body opens scrolled to its middle | Selectable `NSTextView` accessory takes first responder | `isSelectable = false` | 492561b |
| `cm ui snapshot` draws dark alert sheets white-on-white | `cacheDisplay` skips the sheet's visual-effect background, pixels stay transparent | `WindowImage` fills sheets with `windowBackgroundColor` under the drawn pixels | sheet snapshot fix |
| Phone: floating mic drawn over the composer's mic after opening a session from the list | Visibility read from a dock slot that views set in `onGeometryChange` and cleared in `onDisappear`; the list's toolbar mic cleared the session's entry, and on iOS 26/27 a pushed screen gets `onDisappear` right after `onAppear` with no second appear | The plugin says which screens have their own mic (`listHasMic`/`detailHasMic`), `floatingMic` is derived from navigation state; `.voiceDock()` frames, keyed per view, only place the panel. UI test pushes the session 3× | mic dock fix |
| Last line of a transcript message with a table draws over the card below | `ProseText.sizeThatFits` measured at the proposed width but reported the narrower used width; the view got that width, `NSTextTable` re-laid its columns and the text grew a line | Report the narrower width only when re-laying at it keeps the height; snapshot flag `text-overflow` | fix(agents) prose table overflow |
| Phone: floating mic over the back button on a backlog task opened straight from a link or Return | The Backlog list's search-bar mic, still in the stack under the task, kept its `.voiceDock()` frame near the top, and the task screen has no mic of its own to register a later dock, so the floating mic's clearance lifted it to the top | `.voiceDock(active:)`: the search bar's mic docks only while its list is the column on screen (`preferredColumn != .detail`), undocking when a detail covers it. UI test opens `backlog/4` and checks the mic sits in the bottom half | phone backlog search |
| Phone: tapping a "Problem report sent" note in the Agents list opened "Couldn't Load the Transcript · unknown agent session: <UUID>" | A row with no `.tag` inside `List(selection:)` gets its `ForEach` id as an implicit tag when the id type matches the selection (`String`), so the note's UUID became `navigation.detail` | `.selectionDisabled()` on `QueueNoteRow` and the Starting `QueuedLine`. UI test sends a report, taps the note in Agents, checks no Session screen opens | phone queue note |
| Phone/iPad: a long session (1500 entries) opens in seconds and scrolling freezes for seconds | The transcript is an eager `VStack` (a `LazyVStack` under a bottom anchor lands on its height estimate), so every body pass lays out every row; `loadTranscript` wrote `transcriptErrors[session] = nil` on each poll, and an `@Observable` dictionary subscript write notifies even when the value stays nil, so a running session re-laid the whole transcript every 2 s | Draw the last 60 rows with a "Show 100 earlier · N left" row on top; write observed dictionaries only when the value changes (`if dict[k] != nil { dict[k] = nil }`). Kit test with `withObservationTracking`, XCUITest on `-longTranscript` | perf(companion) long transcripts |
| Phone: the workspace screen's title opens inline (small, centred) one time and large the next | `.navigationSubtitle` or a `.largeSubtitle` toolbar item on a screen pushed into the collapsed split view's content column opens its large title collapsed on iOS 27, even with `.toolbarTitleDisplayMode(.large)`, and pulling down doesn't expand it; only a swap of the column's content (a tab switch) brings it back | The Mac line is the list's first section header (`MacLine`/`MacLineSection`) on the workspace, Inbox and Mac details; no subtitle in the bar. UI test enters the workspace and Inbox 3× with 1 and 3 Macs, checks the large title on entry, back from a session and on Backlog | fix(companion) large titles |
