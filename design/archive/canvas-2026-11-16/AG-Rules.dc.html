A · one tree, in detail (questions 1–4)

1 · Where they live

Docked at the bottom of the sidebar, outside the scrolling tree, in this order: Service, Land gates, Graphs (Graphs at the very bottom). They stay in sight however long the tree is and however far it is scrolled; the tree fades out where it meets them, and a short tree leaves empty space above them. Service moves out of the tree into the dock (docs/agents.md § Service sessions changes); Closed stays in the tree, last, as today. Graphs holds “How graphs work” and the definitions; Land gates holds “How land gates work” and one row per gated repo. The UI says land gate everywhere a graph named “Review gate” can also show. No tabs, no extra chips.

2 · Runs and definitions

A run row stays in the worktree group where the run works, with its node sessions under it, as today. ↩ or a click opens the run page in the Agents main pane (diagram, Input/Turns/Definition, History, Open ‹node› ⌘↩, Stop run ⌘.), with a crumb Agents / main / Review gate · #4; ⌘[ goes back to the session you came from. Folding moves to ← → and the chevron, the same as every other tree row. A definition row opens the definition page: Description, Input + Run ⌘↩, Turns, the diagram, and Runs of this graph (all of them, newest first). That is where a run starts; ⌘K also offers “Run ‹graph›…”.

3 · Ended and emptied runs

A run follows its sessions. While any node session is open, the run stays in its worktree group; ended runs fold themselves once you have opened them. When the run has ended and none of its sessions is open, the run row moves to Closed with its sessions under it. When its sessions are deleted after 30 days or archived, the row stays, built from the run itself: a faint graph glyph, “no sessions”, and the run page still opens with input, turns, diagram and History (Open ‹node› is gone). It leaves only through Remove run…. Side by side: a run that asks you itself has an amber glyph and the detail “asks you”, counts once in Needs you, and its page carries the request card; a run whose node waits has a plain glyph and the pointer “→ Coder”, and the amber sits on the Coder row only.

4 · Land gates

The gate page (settings, Pause P, Edit E, Delete ⌘⌫, Verdicts, findings) opens from Land gates in the dock; New land gate is + on that row and in ⌘K. Reviewer sessions move under their lander, named “Round 2 review”, with the verdict as detail (“changes”, “approved”, “reviewing”) instead of the notify level. The lander's own detail stays the gate state (review… / asking). The gate row's detail is a pointer, “1 asking”, never a second amber. A changes verdict is history: plain ink, also on the findings card (decided). From the lander, the Land anyway / Stop card links to its rounds on the gate page.

The dock (16 Nov)

The user's change to A: Graphs, Land gates and Service pinned at the bottom of the sidebar, outside the scrolling tree. Boards: AG-A-Run-1280-Mate (all folded; Service asks), AG-A-Gate-1280-Mate (Land gates open; Graphs has one to trust), AG-A-Tree-640-MateLight (Graphs open in the drawer).

Unfolding

A docked row unfolds upward, inside the sidebar: the dock grows over the tree, which keeps its own scroll above it. One docked row opens at a time; opening another folds the first. An open row shows at most 6 rows, then scrolls inside (“up to 6 rows, then it scrolls”), so the tree never loses more than about a third of the sidebar. Its rows open their page in the main pane like any tree row. Rejected: a list page in the main pane — two steps to reach a definition, and it replaces the run or session you were reading. A popover — gone the moment you click into a page, so it can't stay open beside the work.

Needs you

Amber goes where the answer is. Service: when the voice session asks, the docked row turns amber, “asks you”, and counts once in Needs you; unfolding shows the Voice row in amber. Graphs: when an untrusted graph waits to run (a trigger, a cron job or a run asked for it), the row reads “1 to trust” in amber and counts once; the definition row reads “trust?”, and Trust… is on its page. Land gates: “1 asking” in plain ink — a pointer, because the answer is the Land anyway / Stop card on the lander in the tree, which already counts. Nothing else on a docked row is amber.

Keyboard

Tree and dock are one list for j/k: j past the last visible tree row steps onto the first docked row (Service), k from Service steps back to the last tree row; the tree keeps its scroll. On a docked row, → or ↩ unfolds it upward and ← or Esc folds it; inside, j/k walk its rows and ↩ opens the page. / filters the tree and the dock together, and a match in a folded docked row unfolds it. ⌘K “Open land gates” and “Run ‹graph›…” land in the dock. No new keys.

640 drawer

The ⌘B drawer is the same sidebar: the tree scrolls, the dock sits at the drawer's bottom, and an open docked row grows upward inside the drawer with the same 6-row cap (AG-A-Tree-640-MateLight).

Phone

The phone does not dock them. Closed, Service, Land gates and Graphs end the Agents list, as in C-AG-A-Agents: the bottom of the phone screen already belongs to search and voice, and a docked strip there would sit under the thumb next to them. What made the dock worth it on the Mac — something that asks while scrolled away — is covered differently: anything that asks inside them is listed at the top, in Needs you (Voice in C-AG-A-Agents), and the row at the end reads “1 asks” in plain ink.

7 · Phone

Run rows show in the Agents list at all times, like the Mac: a run with its node sessions nested under it, in Needs you or Running by the run's own state (C-AG-A-Agents). Closed, Service, Land gates and Graphs end the list as ordinary rows, not docked (see “The dock · Phone” above); anything that asks inside them is listed at the top, in Needs you. Graphs lists the definitions and the ended runs (C-AG-A-Graphs-Light); a definition opens with Input and Run; new graphs are written on the Mac. A run opens the native run screen, also when its sessions are gone; an ended run offers Run again with this input, and Remove run… stays on the Mac (C-AG-A-Run). Land gates opens the gate screen as SDUI: the landing that asks first, settings, verdicts, Pause; Edit and New land gate stay on the Mac, because the phone draws no sheet (C-AG-A-Gate-Light). A phone that hasn't been updated loses More → Graphs and More → Gates: its More lists exactly the sections the Mac rail shows, so keeping them would keep the two rail items on the Mac. Its native run screen keeps working through command aliases, and the lander's Land anyway / Stop card still shows; definitions, ended runs and land gates are out of reach on that phone until it is updated.

btree row prop open: the view the main pane shows for this row (session, run, definition, gate) — today only sessions open.
btree prop dock: sections pinned under the scrolling rows, each {id, label, icon, detail, attention, rows, add, cap}; add is the + action (New land gate…, New graph…); the phone renders the same sections as ordinary rows at the end of the list.
cWords: “Land gates”, “How land gates work”, “Round 2 review”, “asks you”, “→ Coder”, “no sessions”, “Runs of this graph”, “Open run”; land gate everywhere “gate” could mean the Review gate graph.

dDocked sections carry attention, decided in the plugin: Service = asks when a service session needs you (amber, counts in Needs you); Graphs = asks when an untrusted graph waits to run (amber “1 to trust”, counts); Land gates = pointer (“1 asking”, plain), since the answer is on the lander.
dagents.runs: id, graph, title, worktree, state (running · asks · ended · stopped · failed · emptied), detail, needsYou, request, pointer (node id), sessions[], home (group · closed). Built from the run, so it survives its sessions.
dReviewer: parentId = lander; gate = {round, of, verdict, findings} replaces the notify detail. Gate rows: {repo, active, asking count}.
dPhone run screen: Run again with this input on an ended, stopped or emptied run — a plugin command that starts a new run of the same graph with the stored input, in the same worktree; the new run opens.
dLink targets: bell, notification, Triggers G, Code chat → agents/run/‹id›, agents/graph/‹name›, agents/gate/‹repo›.
dOld phones: nothing to keep. Their More lists exactly the Mac rail's sections (the same rail filter), so with the two rail items gone they lose More → Graphs and More → Gates. Keep the command aliases the native run screen uses, and keep sending the lander's Land anyway / Stop request.
