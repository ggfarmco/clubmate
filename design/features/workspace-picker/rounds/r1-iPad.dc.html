Workspace picker · round 1 · iPad, where it differs

iPad · the sidebar is the picker

With .sidebarAdaptable the sidebar already lists workspaces, so it takes the same row rules and the capsule hides. With the sidebar hidden, the capsule opens C as a popover, not a sheet.

Sidebar sections are system TabSections with a custom header (colour dot, presence, info button). Folded state is remembered per Mac; the current Mac always opens.

Selection: the current workspace gets the accent selection fill in the sidebar, the accent checkmark in the popover. The tab (Agents) keeps the system tab tint.

With A or B the sidebar is the same; only the popover changes: A stays a system menu, B shows the cards at 375pt.
