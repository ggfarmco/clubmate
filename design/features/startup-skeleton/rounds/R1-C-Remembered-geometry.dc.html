C · Remembered geometry

Cache only the geometry (which panes are shown and how wide), no plugin data: the frame is right from the first frame, the rail stays neutral, every pane uses one shape.

For

  • No layout jump: panes are where they will be.
  • The cache holds only booleans and widths, no icons or kinds from plugins, so it can’t go stale in a visible way.

Against

  • The rail is anonymous: no orientation in the first seconds.
  • One shape for all: list rows over a terminal, top-down rows where a transcript is bottom-up.
  • Costs the same mechanism as A (a client cache) for less of the benefit: adding icon and kind to the same record is a few fields.
