Architecture overviewstaleupdated Nov 16 18:20 by Claude
socket1 of 4nnextNprevious⎋clear

Clubmate is a native macOS IDE built around your own Neovim, real terminals and coding agents. A Go core owns all state and processes. Features are plugins that render UI as data (SDUI). A thin SwiftUI app draws that UI and hosts terminal surfaces.

Processes

  • clubmate-core (cmd/clubmate-core): a single daemon per user, guarded by a lock in the state dir. It listens on a unix socket in the runtime dir and outlives the app. The app starts it on demand (CoreLauncher), as does the CLI.
  • clubmate-session (cmd/clubmate-session, internal/sessionhost): one PTY host per terminal session, in its own session (setsid). It keeps a scrollback ring, so a terminal or the editor's nvim survives an app or core restart and is reattached.

Recommendation and handoff

Pick B · Margin. The page gets a left edge it shares with the header, a reading measure, one title and a two-line header that matches every other detail view. The width that used to be empty margin now carries what a reader of agent-written pages needs next to the text: where they are, what changed, why the page may be wrong, and what links here.

Why B

  • It fixes what the user named. The left edge is shared with the header, the title appears once, and the content above the first line of text goes from about 170 px to 64.
  • Width becomes information. The wiki is written by agents, so “what changed”, “is this still true” and “who links here” are what a reader checks next. They sit beside the text instead of behind a button.
  • It reuses the house patterns: the Patterns detail header, sec labels, tree rows, list + diff nodes and the narrow-window rules. Only the margin column is new, and it lives in the web view, so anchors work with no new SDUI.
  • It degrades cleanly: 1720 → 1280 keeps the column, 960 → 640 folds it into one row, and below 800 the sidebar becomes the ⌘B overlay.

Ship in two steps

Step 1 · no new logic. Items 1–4, 9, 11–17, 19–23, 31 and the typography table. This is direction A's look with B's header and sidebar grammar: the user's complaint is gone.

Step 2 · plugin logic. Items 5–8, 10, 18, 24–30: the margin column, New to you, the history view and search snippets.
