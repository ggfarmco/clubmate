SDUI protocolupdated 19:43 by you

Plugins describe their views as a tree of nodes; the app renders them and sends events back. The pages in this folder cover the node set and the wire format.

Messages

MessageDirectionCarries
view.setplugin → appa whole view tree
view.patchplugin → appchanged nodes, by id
eventapp → pluginnode id, action, value

Versioning

A plugin states the protocol version it speaks; the app refuses a newer major and renders unknown node kinds as a muted placeholder.
