Rules added

  • An editor is a setting, not a step: Neovim is on, VS Code and No editor are one switch away in Settings and the palette.
  • Neovim asks about your config only when you came to edit, never when you came to review.
  • With no editor, actions that need one are hidden, not disabled or rebuilt.
  • No agent vendor in a headline, a Welcome line or the About line; Claude Code appears where it is a requirement.
