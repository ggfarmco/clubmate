1 · Editor · B, Neovim silently

Neovim is on for every install and first run asks nothing. Only three things change: VS Code is offered in Settings and the palette, the nvim import keeps Neovim's own question at the first plain open of Code, and turning both editors off hides what needs an editor instead of rebuilding a review.

B, in four lines

  • First run: Neovim is on, nothing is asked. r1's editor sheet and r2's offer row are both gone.
  • VS Code is offered in two places only: Settings › General › Editors and the palette (Turn on VS Code…). Never as a prompt.
  • nvim import: keep Neovim's own question at the first open of Code, because that is when your keys matter, but only when you open Code yourself: not when Review changes or Full diff opened it (you came to review). Ask once; Not now leaves the Import… row in Settings and the palette command.
  • No editor: turn both off in Settings. No confirmation, it is one switch back.
