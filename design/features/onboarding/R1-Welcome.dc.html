Clubmate · onboarding · round 1

1 · Welcome

New terminal leaves Welcome. Pick: A · One door. Open folder… is the only primary action, Clone and Home are keyed rows under it, and a Claude Code user gets from launch to an open project in one keystroke.

Keyboard

  • Focus starts on Open folder…: ⏎ or ⌘O opens the picker.
  • ↑↓ moves through Open folder…, Clone, Home and every recent; ⏎ opens.
  • Every row prints its key. The caption at the bottom teaches the keys that have no row.

Where New terminal went

  • No tile. ⇧⌘N keeps working, File › New Terminal and the palette's "New terminal" stay.
  • It stays learnable through the bottom key caption, which costs no row.
  • Home moves from a two-line row (name + path) to one line with what it is for.

What A adds

  • One sentence under the title: what Clubmate is for, said once.
  • Clone repository… (⌥⌘O): clone into a folder you pick, then open it. Optional (new core action, d); A works without it.
  • A setup row under the tile, only when something is missing (see 2 · First run). All good = nothing.
