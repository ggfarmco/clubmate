Rules

  • Nothing runs between launch and the first agent that the user must click through.
  • A check that passes says nothing, except one "ready" caption on the first Agents screen.
  • A failing check shows where the user is (Welcome row, Agents empty), with one fix action, and clears by itself when the check passes.
  • A question is asked where its answer is used: the editor in Code, notifications at the first session, the phone after the first turn.
  • A skipped step never comes back as a modal. It leaves at most one quiet row: Settings › Editor, Settings › General, the status bar.
  • At most three hints, each once per Mac, each a line inside something that exists.
  • No new phone screen. The phone's first screen changes words only.

Open questions

  • Can the agents plugin tell "signed out" before a session starts (credentials present), or only "unknown"? If only unknown, the signed_out state stays in the session, and nothing is shown before.
  • Is a worktree the default for + New, or only New in worktree…? The README says "one worktree per agent"; the empty text is written to be true either way.
  • Clone repository…: build now (d) or leave Welcome at two rows.
  • Is there a domain for a universal link, so one QR code both installs and pairs?
