Rules added

  • No editor is a full answer: every flow works without one, and nothing in the app reads as broken or missing.
  • An editor is offered once, at the first review, the moment it adds something (line comments, notes). After Not now: Settings and the palette only.
  • Actions that need an editor are hidden, not disabled, when there is none.
  • Anything about Neovim's config appears only while Neovim is on.
  • Promo copy names the place first (workshop, Home), the crew second, features last.

Removed from r1

  • r1 Choose your editor in the Code pane (flow step 7), and its keys line.
  • r1 editor import check row inside the editor choice ("Also bring my ~/.config/nvim keys and plugins" stays, but moves to Turn on Neovim?).
  • r1 Settings › Editor row; it becomes Settings › General › Editors.
  • r1 About line and topics git-worktree, neovim.
