Trust and run on the phone

Ruled 18 Nov: Pause no longer releases what a gate holds, so the phone must be able to trust a changed graph. The phone gate page shows what changed and offers Trust and run with one confirm, next to Pause the gate. There's no Open graph on the phone.

What the phone shows, in both directions

  • Where you find it. Whenever a graph changed, the Gates dock row (“1 to trust”, amber) and the Gates screen's top row show it: “Done · plans and specs”, then “Graph changed: trust it · 1 waits”. Only while the gate holds something does it also get a Needs you row, counted once however many things wait. The held sessions stay under Running with “waits for trust” and don't count again. Each opens the gate page.
  • Versions. “Pinned 3f9a1c · now 8b02e7 · 1 of 4 steps changed”.
  • Steps. Each changed step is open, with its kind and its − / + lines in mono. Added and removed steps say so. The unchanged steps fold into one line: “Simplify, Fable review, Summary: unchanged”. Every − and + line always shows, however long the diff; only runs of unchanged context inside a step fold (“12 unchanged lines”). A long prompt rewrite makes a long card, and the page scrolls.
  • The waiting line, per point: “1 done turn waits: ‹title›”, “1 landing waits: ‹branch› into ‹base›”, “1 call waits: ‹match› in ‹session title›”; more than one: “2 calls wait: ‹first title› +1”. The gate page header reads “graph changed ‹age› · N waiting for trust”.
  • Trust and run (primary) asks once, in a system alert: Trust this version of Plan pipeline? / What the gate holds is reviewed by it. / Cancel · Trust and run. Then the card goes away, and the held thing's round line reads “round 1 reviewing”.
  • Pause the gate (plain) needs no confirm. It leaves what's held held.
  • iPad: the same card in the detail column. Only the diff's width changes, so it has no board of its own.

Two directions

A · The trust card on the gate page

recommended

The Mac's trust card on top of the phone's gate page: read the change, tap Trust and run, confirm once.

For: It's the same card and the same place as on the Mac, so there's nothing new to learn. It fits on one screen, and the confirm is exactly the one you asked for. In SDUI it needs only a diff-lines node.

Against: A long diff pushes Facts and History down the page; only unchanged context folds, never a changed line.

C-TR-A-Gate-Light · C-TR-A-Confirm-Dark

B · A review sheet

more room

A one-line card on the gate page opens a sheet with every step and its diff. The sheet's footer is the confirm.

For: There's room for long prompt diffs, and you read and trust in one focused place. Trust and run in the sheet trusts directly, because opening the sheet is the deliberate step.

Against: It's one more tap and a new SDUI sheet node. The Mac has no sheet. And the confirm becomes a footer sentence rather than the alert you asked for.

C-TR-B-Sheet-Light

Recommendation

A. It matches the Mac's trust card, uses the confirm you specified, and graph changes are usually one or two steps. B earns its place only if agent-prompt diffs turn out to be long and frequent; its sheet could be added later without changing anything else.

Handoff

aPhone gate page: the trust card as built (one-line title, versions line, each changed step's name above its − / + lines with no step number or box, unchanged steps folded into one line, the waiting line, Trust and run first and Pause the gate after it, wrapping), and the confirm alert.
bSDUI: a diff-lines node (mono − / + lines, tinted; never folds a − or + line, folds only runs of unchanged context into “N unchanged lines”) and a system confirm action (title, message, Cancel, primary).
cWords: “Graph changed: trust it · N waits”, “Pinned ‹a› · now ‹b› · N of M steps changed”, “‹steps›: unchanged”, “Trust this version of ‹graph›?”, “What the gate holds is reviewed by it.”, “Held by 2 gates”, “held · ‹match› +1”, “N graphs reviewing”, “2 gates still ask for changes”, “Run it without another review?”, “N unchanged lines”, “1 done turn waits: ‹title›”, “1 landing waits: ‹branch› into ‹base›”, “1 call waits: ‹match› in ‹session title›”, “graph changed ‹age› · N waiting for trust”.
dTrust from the phone re-pins exactly as the Mac does. A gate waiting for trust counts once in Needs you only while it holds something; with nothing held it shows only on the Gates dock row and the Gates screen. Several gates on one call: the call runs when all approve; on changes, wait for every gate, refuse once, then steer one message with every gate's findings (a section per gate, command order; queued if the turn already ended); one rounds-used card per call; ⌥1 overrides all gates on the call.
