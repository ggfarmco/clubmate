Row. Label("Home", systemImage: "house"). The subtitle is “n waiting” only when n > 0, exactly as for a project. No “pinned”, no “always”, no badge.

Order. In each Mac section the client puts the workspace with home: true first. The rest keep the core order (most recently opened). A Mac whose core sends no Home gets no Home row; the client never makes one up.

Selected. The system checkmark replaces house, as it replaces folder today. The capsule reads “● Home ⌄”. The dot is that Mac's identity colour, so two Homes on two Macs are told apart by the dot and by the section, as shop and shop-api are today.

Cannot be removed. The menu has no remove action for any workspace, so nothing changes here. If Mac Details lists workspaces with Close or Remove, Home's row leaves that action out and is never greyed out. An offline Mac's Home behaves like its other workspaces.
