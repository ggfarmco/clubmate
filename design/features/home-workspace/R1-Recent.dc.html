Welcome and File › Open Recent: Home leads, in a group of its own

Home is not a recent; it is always there. So it does not join the Recent list. It sits above it as a one-row group: house glyph, name, path, ⇧⌘H. Space separates it from Recent, the same way a separator does in the menu. It sits outside the 10-item cap, Clear Menu skips it, and it never shows a trash.
