⌫ on Home: nothing closes. A tile with no ×, and a refusal to explain somewhere.
  • Home is auto-opened in every window, at launch, on ⌘N and on restore, so it is open N times at once.
  • Close Workspace is refused for one tile, so × and ⌫ need a disabled state and a reason. That is a rule only Home follows.
  • Its tile takes the first slot even in a window made for one project.
  • Cost M/L, and it makes Home a different kind of workspace, which the user's rule rules out.
