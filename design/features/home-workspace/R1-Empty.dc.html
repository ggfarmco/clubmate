Why say more, and why not much more

  • Say what it can see. Home's one difference is that it can read everything and change nothing. That can't be seen anywhere else in the UI, so it goes in the one place a first-time user reads.
  • One prompt to try, as text. “What waits for me today?” is the question Home exists for. It is quoted in the text, not prefilled and not sent, so nothing runs and nothing new is needed in the composer.
  • One action. A project's Agents empty state has none; Home gets New session ⌘N, the header's + action, because the node allows exactly one.
  • Backlog and Wiki: one phrase each. “Outside your projects” sets the scope. Everything else is the project's words, so Home reads as the same kind of workspace.
  • Not added: a tour, a second action, example prompts as chips, a card. Cards are for things that ask or change.
