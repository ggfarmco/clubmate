Keep Awake · Round 2

5 · Words and data

The plugin still decides every word. Besides text and detail, clients need the hold lines and one choice: which of the three is active (or none), plus the hours when it's the timed one. The labels for the choices come from the plugin too, so the Mac menu, Settings and the phone can't drift apart.

Picking a choice replaces the current one; picking another number of hours restarts the clock. Turn Off ends your choice only, never an agent's hold. Keep the screen on applies to everything. A closed lid sleeps a laptop on battery whatever holds it.

What the plugin sends

One object for the status bar, the menu, Settings and the phone. Every string is shown as is. Shape only; field names are the plugin team's call.

{ "text": "Awake until 18:00 +1", "detail": "Kept awake by you until 18:00 and by an agent's release build.", // the one choice: "hours" | "agents" | "on" | null (off) "mode": "hours", "hours": 4, "value": "Until 18:00", // phone picker value; Settings' muted end time // lines under the menu's first line; the phone nests only kind "agent" "holds": [ { "kind": "you", "title": "You", "trailing": "for 4 hours · until 18:00" }, { "kind": "agent", "title": "release build", "trailing": "Ship 2.4 release · ≤ 20:40", "session": "…" } ], // the words for the switch, owned by the plugin "labels": { "section": "Keep Awake", "hours": { "title": "For Hours", "active": "For 4 Hours", "options": [ { "hours": 1, "title": "1 Hour" }, { "hours": 2, "title": "2 Hours" }, { "hours": 4, "title": "4 Hours" }, { "hours": 8, "title": "8 Hours" } ] }, "agents": { "title": "While Agents Work", "subtitle": "Running or waiting for you" }, "on": { "title": "Until Turned Off" }, "off": { "title": "Turn Off" } }, "awake": true, "armed": false, "laptop": true, "onBattery": false } // clients send back one of: set({ "mode": "hours", "hours": 2 }) · set({ "mode": "agents" }) · set({ "mode": "on" }) · off()

Edge cases

Hours run outMode goes to none (Off). It does not fall back to a previous choice.
Turn Off with an agent's holdYour choice ends; the cup stays filled with “Awake · release build” until the build ends.
While agents work, on battery, agent's own holdThe agent's hold keeps it awake anyway (holds work on battery); the choice waits for power.
Agent asks for more than 12 hClamped. Its line says “≤ 20:40”: the cap, not a promise.
Hold ends while the menu is openThe menu doesn't change under the pointer; the next open shows the new state. The bar updates at once.
For 8 hours past midnight“Until 02:00”. No date needed.
Phone and Mac change it at onceLast write wins; both re-render from the plugin's next state.
Plugin not runningNo cup in the bar; Settings shows the standard stopped header; the phone hides the group.
