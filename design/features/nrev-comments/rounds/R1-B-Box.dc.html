B · Box: a frame of box-drawing glyphs in one accent

Each open comment gets a frame: the header sits in the top border and a bottom border closes it. One colour for every type (lime); only the issue title turns amber. No fill.

1 Separation. A frame ┌─┐ │ └─┘ from the indent to the pane edge, below the line. Two extra lines per comment (top and bottom), so seven comments cost 14 more lines than A.
2 Colour. One accent for all: lime frame and title, the icon and type word tell the types apart, issue title amber. Lime is also keywords and the cursor line number, so frames compete with code.
3 Header. Inside the top border: icon, type, and the keys hint just before the corner, only on the comment under the cursor.
4 Resolved · drifted. Resolved: ╶─ ✓ suggestion · resolved · … in grey, no frame. Drifted: the frame turns dashed (┄ ┆) and amber, with ⚠ code changed.
5 The code line. Sign ✎ only (lime, amber for issues). No number colour: a lime number reads as the cursor line.
Blame. Right-aligned and short, as in A. Next to a frame it still has the same grey italic as the resolved lines.
