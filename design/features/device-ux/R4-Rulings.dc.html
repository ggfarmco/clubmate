N1No band above the list bar: the list column's bar is the first thing under the status bar (y 24).Tab bar hidden (N2) removes the band; nothing custom.—
N2Sections become icon tabs at the bottom of the list column, as on the iPhone; the top tab bar is hidden, never folded. Workspaces leave the tab set: capsule menu only.Keep TabView(selection:) for state; on iPad regular: .tabViewStyle(.tabBarOnly) + .toolbarVisibility(.hidden, for: .tabBar); tabs = ToolbarItemGroup(placement: .bottomBar) in each list root with icon+label buttons bound to the selection; ToolbarSpacer(.fixed) + Search. Drop the workspace TabSection.iPadOS has no bottom tab bar: these are toolbar buttons. Costs: no tab customization; ⌘1–⌘4 added by hand (.keyboardShortcut); VoiceOver needs .isSelected + “tab” hint; tabs leave with the list when it collapses.
N3One 680-pt measure for title, meta and body; no large-title band; tree rows one line.Detail: .navigationBarTitleDisplayMode(.inline); tree rows .lineLimit(1); list .searchable.Title + meta move into the document (b): the large title cannot follow a centred measure.
N4Scrolled page = one 50-pt bar (inline title + actions); scrolling on enters reading mode; code blocks scroll sideways with a fade.Inline title shown once the document's H1 passes under the bar (scroll offset); .toolbarVisibility(.hidden, for: .navigationBar) in reading mode.H1-under-bar trigger is ours (web view scroll offset). Code scroll is document CSS (b), iPad only.
