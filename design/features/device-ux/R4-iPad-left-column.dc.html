The list column

One column for every section: workspace bar on top, the section's list as iPhone-style grouped cards, icon tabs at the bottom. The system sidebar button collapses it.

Spec

  • Top bar (y 24, 50 pt): sidebar toggle · workspace capsule · Inbox · Voice · create. No title: the selected tab names the section.
  • Rows: grouped white cards on the system grouped background, 12 pt side inset, min 52 pt; no chevron, no count. Selection = system selection tinted Mate.
  • Filters and section headers scroll away; the bar gets the system soft scroll edge.
  • Bottom: tabs Agents · Backlog · Wiki · More (icon + 10-pt label, as iPhone) in one glass group 56 pt high, Search apart; 20 pt from the bottom.
