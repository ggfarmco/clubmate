Checkout flow

Guides · updated 08:41 by agent

Back to the shop wiki. This page follows a cart from the moment the user taps Pay to the moment the order is confirmed or the cart comes back to them, and names the service that owns each step.

Part 1 · Validate

Validate checks that every item is still sold, that the address can be shipped to, and that the totals the app shows match the totals the server computes. A mismatch stops the checkout before any stock is held, so nothing has to be undone.

Part 2 · Reserve

Reserve holds the stock for ten minutes. The hold carries the idempotency key of the checkout, so a retry of the same checkout finds its own hold instead of taking a second one.

Part 3 · Charge

Charge calls the payment provider. A timeout is retried with the same key up to three times with backoff of 1, 4 and 9 seconds; after the last try the cart goes back to the user with the message “Payment didn't go through”.

Part 4 · Confirm

Confirm turns the hold into a sale, sends the receipt and releases the cart. It never calls the provider again.
