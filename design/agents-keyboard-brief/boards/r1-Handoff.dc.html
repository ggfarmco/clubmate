Recommendation: B · Modes, with ⌃⇥ for the last session

B carries the grammar the tree already has (j/k, h/l, g…) into the transcript, makes ⎋ mean the same on Mac and iPad, and gets from the prompt to the tree with ⎋ ⎋. From C it takes the one thing B does slowly: the last-session hop, the most frequent jump, moves to ⌃⇥ — free once the ladder replaces A's ring. The ⌃⌘ session layer is shared by all three. Pins (C) and the held switcher can come later if numbers by position prove too jumpy.

Considered and dropped

  • ⇧⌘1…6 — ⇧⌘3/4/5/6 never reach the app.
  • ⌥⌘1…9 — free, but drop ⌘ and ⌥1 answers a card. ⌃⌘ fails safe.
  • ⌃⌘0 for last — works (A, B) but is a long reach; ⌃⇥ is one hand.
  • ⌃H in the composer — deletes back in every Mac text view.
  • Digits inside a held-⌃ switcher — ⌃+digit is a Spaces key.
  • Esc stops only while running — the same key meaning two things by state is how turns get killed.

Rules

01

One mark

The keyboard has exactly one accent mark: the 2 pt bar on a tree row or transcript block, or the green ring on the composer. A selection in a pane without focus is neutral grey (seli).

02

⎋ steps out, never destroys

composer → transcript → tree → composer. ⌘. is Stop on both platforms and the Stop button prints it. For the first 20 ⎋ presses in a running session the status bar adds “⌘. stops”.

03

Bare keys stay out of the composer

Bare keys (j k g i ? 1 2 3) act only in the tree and the transcript, and on a focused card. Chords (⌃⌘…, ⌃⇥, ⌘.) work everywhere.

04

One order

⌃⌘↓, ⌃⌘1–9 and g1–g9 walk the same list: visible rows, filter and folds applied, Needs you mirrors skipped. ⌃⌘3 = ⌃⌘↓ three times from the top.

05

Every jump lands in the prompt

A session switch focuses the composer. With the prompt empty, today's rule makes 1 2 3 / y n answer the card — so ⌃⌘J 1 is “go there, allow once”.

06

Last session

One step of history per window; ⌃⇥ twice returns. A closed session drops out. None: the status bar says “No previous session”.

07

Digits on demand

Hold ⌃ ½ s, or press g: digits replace the row detail on the first nine rows until released. Never printed all the time; width stays for labels.

08

The transcript is a tree

Same keys as the sidebar. Focus arrives on the newest block. While it has focus, new output does not move you; the status bar shows “↓ 3 new · G”.

09

Status bar = the focused pane

Left: the pane name (TREE · READ · TYPE). Right: 4–5 keys for that pane; at 640 pt the first three. After g: the which-key line.

10

640 pt

The tree is a drawer. Focusing it opens it over the main pane; leaving it closes it.

Edge cases

  • Filter chip changes: numbers renumber over what is visible; the hint shows the new digits.
  • Folded parent: its children have no number until unfolded.
  • ⌃⌘J with nothing waiting: status bar “Nothing needs you”, focus stays.
  • Jump to the open session: no change, focus to the prompt.
  • Aside beside: ⌃L from the main pane reaches the aside's transcript; its ladder ends at the parent's transcript, then the tree.
  • iPad reading view: ⎋ leaves reading view first, as today.
  • Drafts stay with their session across the ladder and every jump.
  • Holding ⌃ while typing ⌃A ⌃E: any key cancels the ½ s timer, so no digits flash.

Build notes

  • Mac. Chords as items in a Go menu (discoverable, work while the composer is first responder). The composer passes cancelOperation (⎋) up instead of stopping. Bare keys in the tree and transcript views only. ⌃⇥ caught at window level before the text view takes it. Hold-⌃ from flagsChanged with a 500 ms timer.
  • iPad. UIKeyCommand per chord with a discoverability title; priority over system behaviour for ⌃⇥ and ⎋ inside the text view; ⌃[ as a second ⎋ command; hold-⌃ from pressesBegan / pressesEnded.
  • One table. docs/shortcuts.md, the status-bar hints, the ? sheet and the iPad titles come from one key table, so they cannot drift.

Tests

  • ⎋ never stops on either platform; ⌘. stops from tree, transcript and composer.
  • ⌃⌘3 equals ⌃⌘↓ ×3 from the top, with the Running filter on and a folded group.
  • ⌃⌘J then 1 allows the oldest waiting card.
  • ⌃⇥ ⌃⇥ returns to the start session.
  • No bare key is typed into, or eaten by, the composer.
  • 640 pt: the drawer opens on tree focus and closes on leave.
  • Magic Keyboard for iPad without ⎋: ⌃[ leaves the prompt; ⌘. stops.
