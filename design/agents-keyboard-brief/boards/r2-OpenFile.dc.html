⌘O stays Open Folder…; “open in nvim” moves to gf

r1 put “open the focused file in nvim” on ⌘O, and the diff card already printed ⌘O. But ⌘O is the app's Open Folder…, in the menu and everywhere. The app key wins; the block action gets B's own grammar.

Decision

  • gf opens the focused block's file in nvim. Works in READ on a Read or Edit row, the diff card, or a file chip in an answer. Elsewhere g f does nothing and the which-key line does not list f.
  • ⌘O is Open Folder… everywhere, focus or not. Nothing in Agents overrides it.
  • The diff card's button prints gf only while its block has the bar; otherwise no keycap (a click still works). Full diff keeps ⌘D, which works from any pane.
  • Which-key after g in READ, on a file block: g → f file · 1–7 session · l last · n needs you · t tree · i reply.
  • iPad. No nvim there: gf and the button are offered only if the Companion can open the file on the paired Mac; otherwise neither shows.
