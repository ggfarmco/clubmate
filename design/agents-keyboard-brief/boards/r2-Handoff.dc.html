This replaces the r1 handoff. ⎋ steps out of typing and never ends full screen; ⌘. stops; the transcript moves like the tree; ⌃⌘ is the session layer; numbers belong to top-level sessions only. Mac and iPad share the model; the iPad column names its key.

Decided

  • Pins and the held switcher are out of scope.

Rules

01

One mark

The keyboard has exactly one accent mark: the 2 pt bar on a tree row or a transcript block, or the green ring on the composer. A selection in a pane without focus is neutral grey.

02

⎋ never leaves Agents

Every Agents pane takes ⎋; where nothing applies it is consumed and the status bar says so. No ⎋ reaches the window, so full screen ends only by ⌃⌘F, Globe F or the green button.

03

⎋ steps out, never destroys

composer → transcript → tree → the composer you left. Open things close first: menu, palette, sheet, g…, field text. Empty stops are skipped.

04

A second way out

⌃[ is ⎋. ⌥⌘← ↑ ↓ → go straight to tree, transcript, composer, aside — no ladder, no ⎋.

05

⌘. stops

From any pane, Mac and iPad; the Stop button prints ⌘.. The first 20 times on a device that ⎋ leaves a running turn's prompt, the status bar says “⎋ left the prompt · ⌘. stops” for 4 s. Then never again. No setting.

06

Bare keys stay out of the composer

j k g i ? 1 2 3 act in the tree, the transcript and on a focused card. Chords work everywhere.

07

Numbers never shift

Numbers go to top-level sessions — tasks and graph runs — in tree order, with the filter and folded repos applied. Asides and graph steps never get one, so unfolding a row moves nothing. ⌃⌘↓ still walks every visible row.

08

Every jump lands in the prompt

A switch focuses the composer; with the prompt empty 1 2 3 / y n answer the card. ⌃⌘J 1 = go there, allow once.

09

Last session

One step per window; ⌃⇥ twice returns. A closed session drops out; none left: “No previous session”.

10

Digits on demand

Hold ⌃ ½ s, or press g: digits replace the row detail on numbered rows until released. Any other key cancels the timer.

11

The transcript is a tree

Same keys as the sidebar. Focus arrives on the newest block. With focus there, new output does not move you: “↓ 3 new · G”.

12

Status bar = the focused pane

Left: TREE · READ · TYPE. Right: 4–5 keys of that pane, 3 at 640 pt; after g the which-key line; ⎋ notes replace it for 4 s.

13

App keys win

⌘O stays Open Folder…; block actions use bare keys (gf) rather than taking an app chord.

14

640 pt

The tree is a drawer: focus opens it over the main pane, ⎋ or leaving closes it.

Edge cases

  • Filter chip changes: numbers follow the visible top-level sessions; the hint shows the new digits.
  • A folded repo group hides its sessions, so they have no number; a folded graph or aside changes nothing.
  • ⌃⌘J with nothing waiting: “Nothing needs you”, focus stays.
  • Jump to the open session: no change, focus to the prompt.
  • The hint counter counts only ⎋ presses that leave a running turn's prompt; per device, stored with the app's preferences.
  • Drafts stay with their session across the ladder, the ⌥⌘ arrows and every jump.
  • Holding ⌃ while typing ⌃A ⌃E: any key cancels the ½ s timer, so no digits flash.
  • iPad reading view: ⎋ leaves it first, as today.

Build notes

  • ⎋ sink (Mac). The Agents root view implements cancelOperation: and never calls super. The composer's text view delegate catches cancelOperation: in doCommandBySelector: and hands it to the ladder. Popovers and the palette keep handling their own ⎋. Test in full screen.
  • Chords (Mac). Items in a Go menu, so they show in the menu and work while the composer is first responder. ⌃⇥ and ⌥⌘ arrows caught at window level before the text view. Bare keys only in the tree and transcript views. Hold-⌃ from flagsChanged with a 500 ms timer.
  • iPad. UIKeyCommand per chord with a discoverability title; priority over system behaviour for ⌃⇥ and ⎋ in the text view; ⌃[ a second ⎋ command; ⌘. registered as Stop so the system never treats it as ⎋.
  • One table. docs/shortcuts.md, the status-bar hints, the ? sheet and the iPad titles come from one key table.

Tests

  • Full screen: ⎋ 30 times in each row of the “where ⎋ goes” table — the window stays full screen.
  • ⎋ never stops on either platform; ⌘. stops from tree, transcript and composer.
  • The “⌘. stops” note shows on presses 1–20 that leave a running prompt and never on press 21.
  • Unfold an aside and a graph: ⌃⌘1…⌃⌘9 point at the same sessions as before.
  • ⌃⌘J then 1 allows the oldest waiting card; ⌃⇥ ⌃⇥ returns to the start.
  • ⌘O opens Open Folder… with focus in the tree, the transcript and the composer; gf opens nvim on a focused Edit row.
  • No bare key is typed into, or eaten by, the composer.
  • Magic Keyboard for iPad without ⎋: ⌃[ steps out; ⌘. stops.

Considered and dropped

  • ⇧⌘1…6 — ⇧⌘3/4/5/6 never reach the app.
  • ⌥⌘1…9 — drop ⌘ and ⌥1 answers a card; ⌃⌘ fails safe.
  • ⌃H in the composer — deletes back in every Mac text view.
  • ⌃G, ⌘⎋, ⌃C as step-out — noise, same reach, or read as “stop”.
  • ⌘O for nvim — it is Open Folder….
  • ⎋ stops only while running — one key, two meanings by state.
  • Pins, held switcher — out of scope.
