# Side threads brief

Input for a Claude Design pass on side threads (backlog #601): a read-only forked session opened from an option of a pending question or from a selected passage, with three ways out (promote, send back, close). `prompt.md` is the message for the Design chat. It points at the project's own boards instead of screenshots, since the screens involved (question card, transcript, Agents tree, phone session) all have boards.
