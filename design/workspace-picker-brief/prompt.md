Draw on top of them. 1. Today. The leading glass capsule "● shop ⌄" on every tab root (dot = the Mac's colour, hollow when that Mac is offline) opens a system `Menu` (`client/Companion/App/WorkspaceCapsule.swift`): one section per paired Mac with the header "<Mac name> (N) · online|offline" in small grey text, then Home (house glyph), then one row per workspace (folder glyph, a checkmark instead on the current one, subtitle "n waiting" when sessions need the user), then "Mac Details" (info.circle), and a last section "Pair a Mac". Problems we see in `iphone-menu-real`: a plain system menu; every row has the same folder glyph; Mac Details sits among the workspaces; the Mac header (count, presence) is small grey text; no sense of which workspace has activity (running sessions, sessions that need the user); with 3 Macs × 10 workspaces the list grows past the screen (`iphone-menu-3macs` already cuts Pair a Mac). 2.
