Clubmate · themes

Mate for Ghostty and nvim

The interface is always Mate. The terminal and the editor belong to the user: Clubmate ships these themes and uses them by default, so a fresh install matches end to end, and anyone can switch the terminal or nvim to their own theme without touching the interface.

Every syntax colour passes 4.5:1 on the editor background in both variants. Lime stays for keywords: in the editor it's content, not an action. Diff and diagnostics use the same 15% tone fills as the app's diff cards.

Rules

  • Interface: Mate in every window and plugin panel; dark or light with macOS.
  • Defaults: the embedded Ghostty and the Code editor start on Clubmate / Clubmate Light, switching with macOS.
  • The user's config wins: a theme = in Ghostty or a :colorscheme in nvim replaces ours, and the interface doesn't follow.
  • Accepted: with another terminal theme the panes and the chrome won't match.
  • Files: ghostty/Clubmate, ghostty/Clubmate Light, clubmate.nvim (+ lualine theme).
