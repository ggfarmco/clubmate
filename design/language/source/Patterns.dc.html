Detail view

Cron, Triggers, Backlog, Graph runs and anything a plugin adds later. Built from existing nodes plus one new header node (see handoff).

  1. Header — kind icon · title in heading (wraps to two lines max, then tail-truncates) · state badges. The normal state gets a neutral badge; only attention gets a tone.
  2. Action bar — primary first, then secondary, then ghost; destructive last and pushed right. Every action shows its key. Below 800pt: primary + two, the rest in “…”.
  3. Properties — form grid. Human value first, machine value second in muted code (0 3 * * *).
  4. Sections — caption label, flat content. Quoted user text (a prompt) sits in a surface-1 block; JSON only behind “Show as JSON”.
  5. History / runs — a list; when empty, a dashed in-place empty with the action that fills it.

Empty states

Never “Select an X”. If something exists, show the most recent item. If nothing exists, teach in one sentence and offer the one action that fixes it.

Narrow windows

One breakpoint does most of the work: below 800pt the sidebar becomes an overlay and every pane gets a one-line breadcrumb.

WidthLayout
≥ 1100rail · sidebar 248 · main · optional side panel 392
800–1100side panel becomes a bottom split (Code chat) or closes; sidebar 220
< 800sidebar → overlay on ⌘B; detail gets “‹ Section / position” breadcrumb + j/k; header meta drops to its own line; property key column 88
< 800action bar: primary + two, rest under “…”; graph diagram → node list; tables drop columns in order HISTORY, TIME, MEM
< 800title bar drops the window-count pill; status bar keeps core · waiting · ⌘K
anynothing overlaps: headers are measured, pending permission docks above the composer

Focus model

  • Exactly one pane has focus. Its selected row shows the accent fill and bar; the other panes show selected · idle (fg 9%, no bar). You always know where j/k will go.
  • When the keyboard cursor differs from the selection (multi-select, vim visual), the cursor gets the 1.5pt focus ring.
  • Move between panes with ⌃h / ⌃l (or ⌘[ ⌘]); ⎋ goes up one level (detail → list → rail).
  • Controls get focus in reading order; the primary button is focused by default when a card asks something.
