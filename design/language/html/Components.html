Clubmate · design language

4a · Components — rows & controls

One renderer per node type. Sizes in u; colours are roles from the token sheet. State columns are the same everywhere: default · hover · selected · focused (keyboard) · disabled · loading · error. Shown in Kanagawa — switch it in Tweaks.

list · tree row

  • height rowHeight; padding-inline l; gap m; icon 14
  • label tail-truncates; one detail max, muted, never truncates
  • badge only for a state that needs attention
  • indent u per level; chevron 12 in the indent, not after it
  • j/k move, h/l fold, ⏎ open, ⌘⌫ delete, menu key = menu

button

  • control height 2u (24), small 20, icon-only square
  • primary: accent fill, on-accent text — one per pane
  • secondary: surface-2 + border-strong
  • ghost: text-2, fill only on hover — toolbars, headers
  • danger: danger outline; filled only inside a confirm
  • shortcut printed inside as a keycap; icon-only buttons put it in the tooltip
  • loading keeps the width, label becomes the progress verb

textField · select · toggle · folderField

  • control height; bg (sunken, not raised) + border-strong; radius m
  • focus: accent border + 3pt accent-bg halo
  • error: danger border + one caption line under it in tone-ink
  • select = field with ⌄; opens a native menu; number keys pick
  • folderField shows the path head-truncated (the end is the folder)
  • toggle 26×16; label on the left, toggle at the row's end
