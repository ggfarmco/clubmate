# Round r-dock: where a dock row says what's happening

New small question on this canvas. Put this round on its own page `r-dock`, at most 6 boards, 2–3 directions (A/B/C) with a one-line pitch each.

## Today (screenshot asset `/_blob/5d5d6fa7f67e1ab7b69b1387f4e9e152`, Mac, 640 pane, dark)

The Agents sidebar ends with a pinned dock of three rows: **Service · Gates · Graphs**. Each row has a right-aligned detail in a count column: normally a number (sessions, gates, graphs) and a + on Gates and Graphs.

When something happens, the number is replaced by words:

| Row | Detail by priority |
|---|---|
| Service | `asks you` (attention) › `N` |
| Gates | `N to trust` (amber, attention) › `N asking` › `N landing` (plain) › `N` |
| Graphs | `N to trust` (attention) › `N` |

The user finds it ugly: `1 landing` sits in a column of numbers, is wider than them, breaks the right edge, and the gate count disappears. Their idea: put the state next to the title, e.g. `Gates (1 landing)`, and keep the number in the count column.

## Ask

One rule for all three dock rows and all their states (plain: landing, asking; attention: to trust, asks you), so the count column only holds numbers. Options worth drawing: the state next to the label (the user's parentheses idea), a small badge or dot, a second line, or something better.

- Mac: 640 Mate light and 1280 Mate dark, the dock fragment with Service · Gates · Graphs in a few states (idle, 1 landing, 2 asking, 1 to trust).
- Phone (iPhone, iPad): the same rows show at the end of the run list (`detail` = phone detail); draw them where the Mac rule doesn't carry over as is.
- Keep the language (`AG-Rules`, `GT-Rules`): badges only for attention, plain ink for "something is moving".
