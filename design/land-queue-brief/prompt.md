Hi! New feature canvas "Clubmate · landing queue". Page Today: today's Agents tree on the Mac (1280 Mate dark, 640 Mate light drawer), the iPhone Agents list and the iPad split view; cm.css and c.css are uploaded as assets. Please do one round on page r1, at most 6 boards. The feature: when several agent sessions land into one branch, Clubmate keeps one stored queue per (repo, target branch). Only the head commits; the entries behind wait or prepare; agent commits into that branch are held. The user must see the queue in the Agents tree and be able to reorder it, skip or remove an entry, and answer a Land request. Where it sits: (1) under the integration session (the session on an integration branch's worktree) as a group of rows "Landing into ‹branch›" with a count, then one row per entry in queue order; (2) for the default branch no session owns it, so a "Landing into main" row shows while its queue is not empty: please draw two directions, (a) a row at the tree root above Closed, (b) a docked row with Service, Land gates and Graphs at the sidebar bottom, and pick one; (3) a lone entry is the head at once and shows only on its own session row, no group. Data per entry, decided by the plugin (the UI never derives it): state waiting | ready | head | asks | blocked, mode branch | index (a change staged in the target worktree) | dirty (uncommitted edits that overlap the head's files), place (1-based, head is 1), up to 10 changed files plus "+n more", overlaps (other entries that change the same files), a one-line why ("waits for edits in a.go", "conflicts in b.go, rebase before your turn", "waits for your yes"), needsYou. Entry row = tree row anatomy: glyph, title (truncates), detail on the right = a state word of at most 9 characters, tone only from success/warning/danger/accent/none like the Task tree table (merged ✓ success, failed danger, asking warning, running accent, queued/waits none). Please rule the words, glyphs and tones. My proposal: head running review or test = reviewing/testing, play.circle, accent; head committing = landing, play.circle, accent; asks = asks, exclamationmark.circle, warning; blocked by a session's dirty edits = blocked, none; blocked by the user's own dirty edits or a conflict nobody can fix = blocked, warning (needs you); ready = ready, circle, none; waiting = its place or "waits", circle, none. The group row detail reads "3 in line" or, when something needs the user, "1 needs you" in amber, like the task parent's "2 need you". Marks, never tones: speculative (entry 2 is reviewed ahead on the head's predicted tree; setting, off by default) and carried (its approved review was kept across a base move on other files), as small neutral marks with a tooltip. Actions, user only: Move up, Move down, Skip once, Remove (in a ••• menu / right-click on the row; no new keys unless you need one), and for state asks the Land card (the existing Land request card, see Land card in the Agents transcript) as the row's action. Overlapping files on demand: expand the row or a popover, files shared with another entry marked. Rows must fold at 640. iPhone: a queue as a section or grouped card in the Agents list, the actions by swipe or a ••• menu; entries that need you also show in Needs you; iPad: like the Mac sidebar column. Constraints: Mate palette from cm.css/c.css only, colour is state (warning = needs you, danger = failed, accent = running), names not ids, same meaning on Mac, iPhone and iPad. Boards: (1) Mac 1280 dark: integration session with a queue of 5: a head that tests, a ready entry with overlapping files shown, a waiting entry with the speculative mark, one with the carried mark, one blocked; the group row; the row menu open; (2) Mac 1280: the default-branch queue, directions (a) and (b) with your pick; (3) Mac 640 Mate light: the queue in the drawer, an asks entry with its action, the overlap popover; (4) iPhone dark and light: the list with a queue section and the entry actions; (5) iPad split view dark; (6) a Rules board: the state table (word, glyph, tone, when), what folds when the row is narrow, the marks, what needs you.
