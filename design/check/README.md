# Design check

Input for a Claude Design check of the build against the boards in `design/language` and `design/companion`. Upload `mac/*.png` and `companion/*.png` (or send them from Claude Code as in `design/README.md`), then paste `prompt.md`.

- `mac/`: Mac app screenshots named after their boards. `notes.md` has the capture setup (theme overlay, seed data, sizes) and `fakeagent-script.json` the fake agent's script.
- `companion/`: simulator screenshots named after the `C-*` boards. `notes.md` has the launch args and waits.

To re-capture, follow the recipes in `design/brief/README.md` and `design/companion-brief/README.md`, plus the notes here.
