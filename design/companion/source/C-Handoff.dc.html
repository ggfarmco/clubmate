c

Shared with the Mac renderers

  • Permission ordering: allow_once first and primary; allow_always plain and confirmed; reject_once plain; reject_always behind “more”. One rule in the shared model, both apps render from it.
  • Plan: no strikethrough; a prose plan followed by a plan entry folds into the card.
  • Tool groups: consecutive calls collapse into one summary row; failures expand.
  • User message: neutral surface, not the accent.
  • Status vocabulary: Waiting for you · Asking you · Running · Stopped · Done · Closed — the same words in list rows, headers and notifications.
a

Companion-only SwiftUI

  • Accent → Mate green (#A6D85B dark / #357A27 light); success → teal; warning amber; danger red — the same values as the Mac's Mate theme. System surfaces and label levels. The palette does not follow the paired Mac.
  • Mac colours (C5): six tokens, dots and tinted Mac glyphs, picker in Mac details; hidden with one Mac.
  • Permission card: Allow once full width on row 1; Always allow… + Reject on row 2; confirm sheet for Always.
  • Composer: right slot always Send / Queue; Stop into ••• with one confirm (header button on iPad).
  • Pending request / question docked above the composer; transcript inset below the glass header.
  • Macs screen: “Needs you” on top; per-workspace “2 waiting”; offline Macs dimmed.
  • Workspace list: status glyph + state line, no pills; subagents nested.
  • Inbox: Waiting for you / Earlier; dots only on unseen actionable items.
  • NavigationSplitView with width breakpoints: stack < 600pt, two columns 600–1000pt (Fold open, iPad portrait), three above (iPad landscape).
  • No swipe actions that allow, reject or stop. Hardware keys ⌥1 ⌥2 ⌥3, ⌘⏎ on iPad / Fold.
Open questions
  1. Fold metrics. Layouts are keyed on width, so the Fold should just work; the open-state board assumes ≈4:3. Re-check against Apple's numbers once they're published, especially the cover screen width.
  2. Always allow from a notification. Proposal: notifications offer Allow once and Reject only; Always needs the app (and the confirm sheet). Agree?
  3. Stop. One confirm, or a long press? I chose a confirm in the ••• menu — slower, but it can't happen by accident.
  4. Nesting depth. Can subagents have subagents? The list nests one level; deeper chains would need a breadcrumb.
  5. Title-bar dot on the Mac. On by default once a second Mac is paired, or off until you turn it on in Settings → Remote?
