Permission request

  • Order is fixed: Allow once (filled, full width, row 1) · Always allow… (plain) · Reject (plain, danger ink) — row 2
  • The exact command in mono; the reason in one caption line
  • “Always allow…” never acts directly: a sheet shows the rule it will store and asks again; the confirm button is plain, Cancel is bold
  • reject_always lives in that card's ••• (“Reject and don't ask again”), never as a fourth button
  • Answered: collapses to one muted row in the transcript
