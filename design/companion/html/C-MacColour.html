C5 · A colour for each Mac

With two or more Macs paired, each one gets a colour, so you can tell at a glance which Mac is asking. The colour is a name tag, not a theme: buttons, status and selection keep their roles everywhere, so Allow once is always the same green button.

Palette

Six colours, none of them a role

Each hue sits at least 30° away from the roles: accent green 84°, warning amber 39°, danger red 5°, success teal 169°. All six pass 3:1 against the surfaces in both appearances (non-text contrast).

They are close in lightness, so the Mac's name is always next to the colour. Colour is never the only cue.

The Mac sends a token (blue), not a hex value. Each app maps it to its dark or light value, and a future seventh colour doesn't break older apps; they fall back to graphite.

Rules

  • Only with two or more Macs. With one Mac paired there are no dots and no tinted glyphs, and the Mac's title bar shows no dot.
  • Always next to the name. A dot or glyph is never shown without the Mac's name beside it.
  • Never on buttons, status glyphs, selection, the unread dot, row backgrounds, or text. The amber “needs you” glyph is still the thing that catches the eye; the dot only says where.
  • Notifications: iOS doesn't let us colour them, so the Mac's name leads the title: “Mac Studio · shop”.
  • Offline Macs keep their colour; the row dims as before.
  • Default at pairing: the first colour not used by another Mac, in the order blue, magenta, sky, purple, indigo, graphite — neighbours in that order are far apart.
  • Duplicates are allowed if you pick them; the picker shows which Mac already uses each colour.

Where you choose it

  • The colour belongs to the Mac. It is stored on the Mac and sent at pairing, so the iPhone, the iPad and the Mac's own title bar always agree.
  • On the phone: Macs → tap a Mac's name → Colour. The change is sent to the Mac; while the Mac is offline the picker is disabled (“Connect to change”).
  • On the Mac: Settings → Remote → This Mac's colour, with a preview of the title bar and of a phone row.
