B · Get out of the way

Reading is its own mode. Scroll down a wiki page, a doc or back through a transcript and the bars, the banner, the composer and the mic all step aside; only the status bar stays. Tap the text or scroll up a little and they float back over it. A request that waits for you never hides: it shrinks to an amber pill in reach. On iPad, one key turns the whole window into a reading view.

Rules

  • Reading surfaces only: wiki pages, docs, and a transcript when you are not at its live end. Lists, forms and the live end of a session keep their chrome.
  • Scroll down = chrome away. Scroll up 24 pt or tap empty text = chrome back, floating as glass over the text so nothing reflows. A link works on the first tap.
  • Header and actions follow A when the chrome is visible (one bar, actions as bar buttons).
  • A waiting request becomes an amber pill at the bottom centre: what it wants + Answer. Tap = back to the live end with the card open. Other sessions waiting show as “+1” in the same pill.
  • VoiceOver, Switch Control or Reduce Motion on: chrome never hides.

How it works

  1. The checkout holds the reservation for 10 minutes.
  2. A timeout retries the same idempotency key up to 3 times with backoff 1 s, 4 s, 9 s.
  3. After the last try the cart goes back to the user with the message “Payment didn't go through”.
for try := range 3 { err := charge(ctx, key) if !isTimeout(err) { return err } time.Sleep(backoff[try]) }

Decisions

Retries reuse the idempotency key, so the provider never charges twice. See the payments overview.

The charge step fails about 0.4% of the time on a provider timeout. Today the cart is released and the user starts over, which costs about 30 orders a day.

How it works

  1. The checkout holds the reservation for 10 minutes.
  2. A timeout retries the same idempotency key up to 3 times with backoff 1 s, 4 s, 9 s.
  3. After the last try the cart goes back to the user with the message “Payment didn't go through”.
for try := range 3 { err := charge(ctx, key) if !isTimeout(err) { return err } time.Sleep(backoff[try]) }

Decisions

Retries reuse the idempotency key, so the provider never charges twice. See the payments overview. We keep the reservation for the whole retry window rather than re-reserving, because stock can move in 9 seconds.
