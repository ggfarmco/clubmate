Colour roles in the bar

  • Monochrome (system label ink) for every resting item.
  • Mate green (Accent asset, any + dark) only for a live state: listening.
  • Amber (Warning asset) only in direction B for Inbox, never as a plain glyph tint.
  • Red never: no system badge, no destructive role.
  • Caption ink: the system subtitle (offline).

Data

  • Inbox mark, the menu's "n waiting" and the VoiceOver value all read the plugin's needsYou. The client never recounts.
  • Unread Inbox rows count toward the mark (not toward needsYou).
  • Offline text: the Mac's name + the time it was last seen, from the pairing state.

Check on device before merge

  • An empty navigationSubtitle collapses with no gap.
  • The bottom accessory hides with toolbarVisibility(.hidden, for: .tabBar), renders on iPad, and fits the pop budget with the tab bar (else trim it, then B3).
  • An inline Picker in the menu shows row subtitles (else use Buttons with a checkmark image on the current row).
