Root bar today: capsule · inbox · mic · compose

Every tab root (Agents, Backlog, Wiki, More) has the workspace capsule top left and one glass group top right: inbox tray with an amber dot, mic (press and hold), compose. Capsule, inbox and mic are custom SwiftUI views hosted in the bar; compose is a plain native bar button. On iPad the same items sit over the list column.

What hurts

Back swipe from a session to this list: mid-swipe the bar keeps the session's chevron and •••; the root items show only when the swipe ends, with a glass fade. Users read it as a hitch.

Measured main-thread cost of the three hosted items: ~43 ms per push, ~48–58 ms per pop. One hosted item costs ~24 ms even in a bare SwiftUI app; a plain native Button or Menu item costs ~0 and animates with the bar.

Target: root bar cost per pop ≤ ~10 ms, so every item must be native (ToolbarItem / ToolbarItemGroup with Button or Menu and a Label or Image, system glass grouping, system badge).
