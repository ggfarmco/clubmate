Draft rulings

  • Capsule → Menu(workspaceName) { … }, text label only, system glass. The Mac colour dot and the custom chevron go. Mac offline shows in the existing offline row under the title (it already does), not in the bar. Menu content stays as today.
  • Inbox mark → symbol swap, no dot: Button("Inbox", systemImage: news ? "tray.full" : "tray"). No count badge: the "Needs you" chip and the Agents rows carry the count, and the system badge is red, which the language keeps for failures.
  • Mic → native Button("Voice", systemImage: active ? "mic.fill" : "mic"), tap to start, tap to send (press during "sending" still cancels). While listening: accent-tinted glass (.buttonStyle(.glassProminent), .tint(.accentColor)) if the bar keeps it native; else plain mic.fill. Press and hold stays on the composer mic in a session. Offline: mic.slash, disabled.
  • Order → one ToolbarItemGroup(placement: .topBarTrailing): Inbox · Voice · section create. iPad: the same group, sidebar toggle stays its own glass.
  • Must stay: capsule on the leading edge on every tab root; inbox pushes the Inbox page; mic and compose in the same group; 44 pt targets.
  • May change: Mac colour dot, hollow offline dot, amber dot, accent circle drawn by us.
  • Gate: if any item still measures as hosted (> ~10 ms per pop with nav.sh testBackButton / testSwipeBackSlow), drop its extra (tint, prominent style) before changing the look again.
