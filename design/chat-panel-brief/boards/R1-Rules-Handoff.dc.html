Rules, handoff, recommendation

recommended

A · H1 · W1 · K1 · P1+P2

  • Picker A, one list with the suggestion as the focused first row and its reason in the caption; filter field above 9 sessions. Only existing nodes plus two props, and ↩ does what you expect.
  • Header H1: back button with ⌘[, context as composer chips that replace Context ⌘I.
  • Wiki W1: same right column as Code; the margin folds into the R5 fold row while chat is open.
  • Key K1: ⌘B is the chat panel in both sections; ⌃⌘S is the sidebar everywhere, as on the iPad.
  • iPad: side panel in landscape, sheet in portrait and compact. Take C's grouping later if 20+ sessions turn out to be common.

Opening

  1. ⌘B opens the panel on the picker, every time, in Code and in Wiki. Focus lands on the suggestion.
  2. The tree is one SDUI tree from the agents plugin; Code and Wiki differ only in what the plugin is told you look at.
  3. Below 1100 pt the panel stacks under the editor or page; above, it is a right column, default 392, min 320, max half the window, one width per window.

Picker

  1. Order: the suggestion, then every other open session of the workspace by last activity. Closed sessions stay in Agents.
  2. Row: status icon · title · caption (worktree only when not this one · age). Needs you: amber icon + one badge.
  3. The suggestion carries a section label “Suggested” and its reason in the caption: opened this review · gets this review's comments · last used here · newest.
  4. Accent marks the focused row only. The suggestion keeps its label when focus moves.
  5. New session is a secondary button at the foot of the list; it becomes the primary only in the empty state.
  6. Label: “New session for this review” when a review tab is current in Code, else “New session”. Its caption says what it will see.
  7. More than 9 open: the filter field shows; / focuses it at any count; ⏎ in the field takes the first match.

Keys (panel focus only)

  1. ⏎ take the focused row · ↑↓ and j/k move · N New session · / filter · ⌘[ back to the picker from a chat.
  2. ⌘N stays New in each section; a bare Esc stays with the app. ⌫ clears the filter.
  3. ⌘B toggles the panel everywhere; ⌃⌘S toggles the sidebar / list everywhere (K1).
  4. Every key is printed: on the focused row (⏎), on the button (N), in the field (/), on the back button (⌘[).

After the pick

  1. Header: back button with ⌘[ · status · title · worktree when not this one · hide.
  2. Context shows as chips at the top of the composer: file:lines, the review, or the page. A chip opens the context detail (⌘I); × leaves it out of the next message.
  3. Send is the panel's one primary. Names over ids everywhere: session titles, worktree names, page titles.

Wiki

  1. The panel takes the margin column's place; while it is open On this page and Changes fold into the one-row fold above the body.
  2. Wiki has no review: the suggestion is “last used here” (this workspace) or “newest”.

iPad

  1. Landscape, regular width: right panel 400 pt, the list column hides while it is open.
  2. Portrait and compact: a sheet with medium and large detents. Rows 56 pt; key caps only with a hardware keyboard.
